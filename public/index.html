How to read the results

Current

An official source with a date tied to this exact fact supports the claim.

Likely outdated

A recent official source says something different. The AI answer is probably stale.

Supported, freshness unconfirmed

Sources agree, but no date proves the information is still current.

Contradicted by sources

The sources found contradict the claim, but none has a date tied to this fact. Possibly outdated: review before trusting it.

Conflicting

Sources disagree and none settles it. Check them yourself.

Not verifiable

No usable evidence was found. This does not mean the claim is false.

Freshness index (0–100): how recent the dated evidence is, relative to the validity window of the claim type (prices 30 days, API versions 90, companies 180, regulations 365). It halves every half-window: 7 days old for a price = 72. It is not a probability of truth, and it is only shown when a date is explicitly tied to the fact being checked.
