# Notas

Technical notes behind Entrelinhas, written in Portuguese during development.

- `ESPECIFICACAO_FRESHNESS_SCORE.md`: the full contract of the freshness score and the temporal signals.
- `PESQUISA_REFERENCIAS.md`: public research and design choices (source independence, duplicates, dates).
- `DECISOES_TECNICAS.md`: technical decisions and why they were made.
- `historico/`: working logs, plans and audits from earlier stages of the project. They describe the project as it was at the time (some say there is no interface yet, for example) and are kept only as history. The current state is in the main README.
