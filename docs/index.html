      entrelinhas means “between the lines” in Portuguese.

      It reads an AI answer the way a careful editor would. It breaks the answer into single statements, checks each one against today's sources, and shows which still hold, which have changed and which nobody can confirm. Then it rewrites the answer with sources.

      It is not only about dates. Prices, software versions, who runs a company, laws, numbers: anything an AI states with confidence and that may be out of date, or simply wrong.

      From a confident answer
      to a current one.

      Claim identification, freshness detection, live verification and a freshness score for every claim, in one pass.

      1. Split and flag

        The answer is broken into single statements, called claims. Each one is tagged by how fast it can go out of date.

      2. Search live

        Tavily searches the web right now: official sites first, then news and science. Up to five different sources per claim.

      3. Read together

        An AI model reads every source for a claim, knowing today’s date. Calls go through Bifrost, a gateway that switches to a backup model if one fails.

      4. Weigh & score

        Copies count once and official sources weigh most. Each claim gets a freshness score: how recent the confirming sources are, weighted by how many agree.

      5. Rewrite

        Entrelinhas writes the answer again using only what the sources confirm, with a numbered source for each fix.

      From an outdated answer
      to a correct one.

      Not just one verdict for the whole answer. Entrelinhas gives each claim its own verdict, agreement score and freshness status.

      What the results mean.

      Every claim gets one of seven verdicts, grouped in three colors.

      From 0 to 100

      Source agreement

      How many of the independent sources support this claim. 100 means all of them agree; 0 means all of them disagree. Official and scientific sources count most, and copies of the same article count once.

      Freshness

      How recently the sources confirmed this fact. 100 means it was confirmed in the last few days, and the score drops as the confirmations get older. Each kind of fact has its own pace: prices about a month, software versions a quarter, company facts six months, laws a year, and fast official values have their own, like Brazil's Selic rate, about every 45 days. A true claim can still score low when every page that confirms it is old: the verdict says whether it holds, freshness says how recently anyone confirmed it.

      Good to know

      These scores show how well today's sources back a claim. They are not a guarantee: several sources can repeat the same mistake. Before deciding something important, read the quotes behind the verdict.
